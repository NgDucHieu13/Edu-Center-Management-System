# HỆ THỐNG QUẢN LÝ LỚP HỌC TIẾNG ANH (ENGLISH CENTER MANAGEMENT SYSTEM)

## Phân tích yêu cầu & Kiến trúc hệ thống

Yêu cầu bao gồm 2 nền tảng:
1. **Phần 1: Web Admin Panel (Desktop)** - Quản trị viên, Nhân viên, Giáo viên (/admin, /staff, /teacher).
2. **Phần 2: Mobile & Web Portal (Mobile Target)** - Ứng dụng Học viên (Expo React Native / Mobile-first UX).

Theo cài đặt target_device = `MOBILE`, trọng tâm triển khai phiên bản đầu tiên là **Mobile & Web Portal dành cho Học viên** (hoặc đề xuất lộ trình bao quát cả 2). Với yêu cầu thiết kế hệ thống toàn diện, chúng tôi sẽ xác nhận kế hoạch thiết kế và lộ trình thực thi.
